# illogi-city
Suspense. Mystery. Revelations. Illogi-city has it all. This RenPy visual novel follows a stranded bounty hunter's efforts to regain his lost memories, and escape from the prison he knows not why he has been put in.

Playable link - [Illogi-city](https://a-hungrybookworm.itch.io/illogi-city)
Download the source code from the link above!

# Why?
This project was built for Haven Bengaluru, a Hackclub program!

# Coding it!
@Ann_with_an_e, and I, @a-hungrybookworm, coded this project in six hours - at a stretch. We initially looked at the Storyboard tutorial on RenPy, and fleshed out our storyline. We knew it had to be something related to space - and our idea gradually grew from sketches in a drawing book to code on a single computer that we fighted to type on.

We first wrote the skeleton for our code - the bare logic, and then I added the dialogues. @Ann_with_an_e sketched the images and after a lot of trial and error, we exported the game!
